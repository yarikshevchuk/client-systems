# Бачення продукту

## Проблема

Слухачеві лекції, пари чи конференції складно водночас сприймати матеріал і конспектувати. Запис аудіо допомагає лише частково: знайти потрібне місце в півторагодинному записі майже неможливо.

## Рішення

Вебзастосунок, який:

1. **записує** лекцію в браузері або **імпортує** готовий аудіофайл;
2. перетворює аудіо на **зручний конспект** — повний транскрипт із таймкодами, стислий підсумок, структурований план (теми й підтеми) та ключові терміни з питаннями для самоперевірки;
3. дає **швидко знайти** потрібну інформацію: семантичний (RAG) пошук по тексту всіх записів — за змістом, а не лише за точним збігом слів.

## Для кого

- Основний користувач: студенти й слухачі будь-яких лекцій та конференцій — потенційно будь-хто, хто хоче зібрати й систематизувати теоретичний матеріал, який прослуховував. Окремої ролі викладача (масове завантаження лекцій для групи) в MVP немає.
- Типове аудіо: лекції на парі (1–1,5 год), записи онлайн-занять (Zoom/Meet), інші записи тривалістю до 1,5 год.
- Мова лекцій: англійська та українська — потрібне розпізнавання обох.

## Цінність

- Не треба конспектувати вручну — на парі можна слухати й думати.
- Потрібне місце лекції знаходиться за секунди, а не прокручуванням аудіо.

## Цілі

- MVP, що покриває повний цикл **аудіо → конспект → пошук**. Скоуп — у [requirements.md](requirements.md).
- Обсяг проєкту: повноцінний фронтенд + базовий бекенд.

## Не-цілі

- Окрема роль викладача (масове завантаження лекцій для групи) — поза MVP.
