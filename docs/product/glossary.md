# Словник

Одна сутність — одна назва в доках, коді й інтерфейсі.

| Термін | У коді (пропозиція) | Значення |
|---|---|---|
| Запис | `Recording` | Аудіо однієї лекції: записане в браузері або імпортоване з файлу |
| Транскрипт | — | Увесь текст, розпізнаний із запису; складається із сегментів |
| Сегмент | `Segment` | Фрагмент транскрипту з таймкодами початку й кінця |
| Таймкод | `startSec`, `endSec` | Позиція в аудіо, секунди від початку |
| Конспект | `Summary` | Структурований результат обробки запису: транскрипт із таймкодами, стислий підсумок, план (теми й підтеми) та ключові терміни з питаннями для самоперевірки |
| Предмет | `Course` | Дисципліна, до якої належать записи — TBD (Q11) |
| RAG-пошук | — | Семантичний пошук по тексту всіх записів: враховує зміст запиту, а не лише точний збіг слів |

Мова назв у коді — англійська (Q26).
