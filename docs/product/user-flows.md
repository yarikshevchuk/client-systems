# Сценарії та екрани

## Ключові сценарії

### С1. Записати лекцію → отримати конспект

1. Учень відкриває «Новий запис» і натискає «Записати».
2. Після лекції зупиняє запис — аудіо йде на бекенд.
3. Застосунок показує статус обробки; обробка 1,5-годинної лекції займає хвилини (Q17).
4. Коли готово — відкривається конспект.

Транскрипція виконується лише після завершення запису, без наживо-режиму (Q12).

### С2. Імпортувати файл → отримати конспект

1. Учень відкриває «Новий запис» → «Імпортувати файл» і обирає аудіо.
2. Далі — як кроки 2–4 у С1.

Формати: mp3, m4a, wav. Максимальна тривалість файлу — 1,5 год; відео не приймається (Q13).

### С3. Знайти потрібне місце

1. Учень вводить запит у пошук.
2. Бачить фрагменти конспектів, де це є за змістом (семантичний/RAG пошук, Q8).
3. Переглядає знайдений фрагмент конспекту. Відтворення аудіо з цього місця — поза MVP (Q8).

## Екрани

_Кандидати — підтвердити після відповідей._

| Екран | Призначення | Питання |
|---|---|---|
| Бібліотека записів | Список усіх записів, згрупованих за предметом | Q11 |
| Новий запис | Запис з мікрофона або імпорт файлу | Q12, Q13 |
| Обробка | Статус «розпізнаємо / генеруємо конспект» (хвилини) | Q17 |
| Конспект | Конспект + транскрипт + поле для промту-виправлення | Q7, Q14 |
| Пошук | Семантичні (RAG) результати по всіх записах | Q8 |

Екран входу/реєстрації не потрібен — MVP без авторизації (Q10).
