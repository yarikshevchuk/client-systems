# VNS — документація

VNS — навчальна платформа, що замінює ВНС Львівської політехніки для однієї кафедри: курси, лабораторні з дедлайнами
й оцінками, оголошення, запитання до викладача, повідомлення й AI-допомога за правилами викладача. Командний проєкт
з бізнес-аналізу (вимоги, артефакти) і програмування клієнтських систем (код).

Як запустити — у [README репозиторію](../README.md). Тут — що це за продукт і як він влаштований.

## 1. Проблема і для кого

| Хто | Що болить у звичайній ВНС | Що дає VNS |
|---|---|---|
| Студент | Дедлайни розкидані по курсах; незрозуміло, скільки балів уже є і скільки ще можна набрати; питання губляться в месенджерах | Усі дедлайни на головній і в календарі; прогноз оцінки; Q&A всередині курсу |
| Викладач | Ті самі питання в особистих повідомленнях; не видно, хто відстає; AI-інструменти студентів поза контролем | Питання й відповіді в курсі, видно всім; журнал оцінок і аналітика «хто відстає»; AI вмикає й обмежує сам викладач |
| Адміністратор | Облікові записи групи заводяться вручну | Імпорт реєстру деканату з CSV |

## 2. Ролі й можливості

**Студент** бачить курси своєї групи.
- Головна: курси з балами, найближчі дедлайни, завдання, які треба здати.
- Курс: теми, лекції, лабораторні, файли викладача.
- Лабораторна: здача файлу з коментарем, оцінка й відгук викладача; питання до викладача по цій лабі.
- Оцінки: «зароблено / результат за оціненими / максимум» і калькулятор «що потрібно, щоб завершити курс з N %».
- Канали курсу: `#питання` (Q&A з прийнятою відповіддю), `#загальний`, канали модулів і лаб, файли в повідомленнях.
- Особисті повідомлення, навчальні простори (чат, дошка задач, спільні файли, внесок кожного).
- Календар з експортом `.ics`, нотатки до матеріалів, картки з інтервальним повторенням, глобальний пошук.
- Запис голосу на лекції з розпізнаванням мови й синхронним текстом.
- AI-помічник курсу — у межах, які дозволив викладач (див. розділ 3).

**Викладач** керує своїми курсами.
- Курси, теми, матеріали: створення, редагування, порядок, видалення, прикріплені файли.
- Оголошення з закріпленням і списком тих, хто прочитав.
- Перевірка робіт: оцінка й відгук; журнал оцінок з CSV і позначкою «відстає».
- Аналітика групи: середній результат, частка зданих робіт, хто відстає й чому, звіт CSV.
- Прийняття відповідей у Q&A.
- Налаштування AI для курсу і для кожної лабораторної окремо.

**Адміністратор** бачить статистику платформи, змінює ролі користувачів, імпортує реєстр деканату
(номер квитка, ПІБ, група → обліковий запис із поштою й паролем).

**Для всіх:** світла й темна тема; українська й англійська мова інтерфейсу; PWA — застосунок можна встановити,
переглянуті сторінки відкриваються без мережі; сповіщення в реальному часі (оцінки, відповіді, оголошення,
нагадування про дедлайни за 72, 24 і 3 години).

## 3. Правила AI

AI — помічник, а не спосіб списати. Тому правила задає викладач:

1. **Для курсу все вимкнено за замовчуванням.** У «Налаштуваннях курсу» викладач окремо вмикає конспекти лекцій,
   картки з лекцій і запитання за матеріалами курсу.
2. **Для кожної лабораторної — свій перемикач** «Дозволити AI-підказки до цієї лабораторної» (за замовчуванням увімкнено).
   Якщо його вимкнути, у студента на сторінці лаби зникає вкладка «Питання до AI», а текст лаби не потрапляє
   в джерела відповідей помічника.
3. **Відповіді лише за матеріалами курсу й публічними записами лекцій**, з посиланням на джерело.
   Якщо відповіді в матеріалах нема — помічник так і каже й пропонує спитати групу.
4. **Для оцінюваних лабораторних — лише підказки**, не готовий розв'язок.
5. **Ліміт** — `AI_DAILY_LIMIT` запитів на користувача за добу (за замовчуванням 30). Готовий конспект лекції
   зберігається і не витрачає ліміт повторно.

Помічник розпізнає намір запиту: дедлайни, оцінки, тест за матеріалом, картки, конспект; усе інше — запитання
за матеріалами. Ключові слова розуміє українською й англійською.

Без ключа AI працює в демо-режимі (конспект — перші речення, відповідь — найближче речення з матеріалів, картки —
речення з пропущеним словом). З ключем `ANTHROPIC_API_KEY` або `GEMINI_API_KEY` відповідає модель.

## 4. Мова інтерфейсу

Перемикач — кнопка `EN` / `UA` у шапці і кнопка мови на сторінці входу; вибір зберігається в браузері.

- Українські рядки в коді — це ключі. Кожен напис обгорнутий у `t("…")` з [`frontend/src/i18n.js`](../frontend/src/i18n.js).
- Якщо вибрано англійську, `t` бере переклад зі словника [`frontend/src/en.js`](../frontend/src/en.js);
  якщо перекладу нема — показує український текст.
- Змінні частини підставляються через `{назва}`: `t("Видалити «{title}»?", { title })`.
- Повідомлення про помилки бекенд надсилає українською, фронтенд перекладає їх тим самим словником.
- Дати й місяці форматуються під мову (`uk-UA` / `en-GB`).
- Вміст курсів (назви, тексти лекцій, оголошення) не перекладається — це дані викладача.

## 5. Архітектура

```
Браузер (React, PWA) ──HTTP /api──▶ FastAPI ──▶ PostgreSQL 16
        ▲                             │
        └────────WebSocket /ws────────┘   події: нові повідомлення, оцінки, сповіщення
                                      │
                                      └──▶ Claude / Gemini (лише якщо заданий ключ)
```

| Частина | Стек | Де |
|---|---|---|
| Фронтенд | React 19, Vite, React Router, звичайний CSS | `frontend/src/` |
| Бекенд | Python, FastAPI, `psycopg`, PyJWT | `backend/` |
| База | PostgreSQL 16 у Docker, порт 5440 | `docker-compose.yml` |

**Бекенд** — один модуль на область: `auth` (реєстрація, вхід, профіль), `courses` (курси, теми, матеріали, оцінки),
`submissions` (здачі й файли), `announcements`, `discussion` (канали курсу), `dm` (особисті повідомлення),
`spaces`, `study` (нотатки й картки), `ai` і `agent` (AI-функції), `recordings` (записи лекцій), `notifications`
і `notify` (сповіщення), `schedule` (календар), `search`, `admin`. Спільне: `db.py` (схема й функції
`select` / `one` / `execute`), `access.py` (хто що може бачити), `live.py` (WebSocket-хаб).

**Фронтенд** — `pages/` (екрани), `components/` (частини екранів), `components/ui.jsx` (іконки, аватар, модальне вікно,
перемикач, смужка прогресу), `api.js` (запити й формат дат), `live.js` (одне WebSocket-з'єднання і хук `useLive`),
`i18n.js` + `en.js` (мова). Віджети — стандартні елементи браузера, без сторонніх бібліотек інтерфейсу.

## 6. Дані

| Область | Таблиці |
|---|---|
| Люди | `users` (роль `student` / `teacher` / `admin`, група, номер квитка) |
| Курс | `courses` → `topics` → `materials` (лекція або лаба: дедлайн, макс. бали, `ai_on`), `attachments` |
| Здачі | `submissions` (файл, коментар, оцінка, відгук) |
| Спілкування | `announcements` + `announcement_reads`, `messages` (канали курсу), `direct_messages`, `notifications` |
| Простори | `spaces`, `space_members`, `space_messages`, `space_tasks`, `space_files` |
| Навчання | `notes`, `flashcards` (коробка Лейтнера й дата повторення), `recordings` (аудіо + текст по реченнях) |
| AI | `ai_settings` (перемикачі курсу), `ai_summaries`, `ai_messages` (історія помічника), `ai_usage` (ліміт) |

Схема створюється й доповнюється при старті бекенду (`db.py`), демо-дані — `seed.py`.

## 7. Доступ і безпека

- Пароль зберігається як PBKDF2-SHA256 із сіллю; після входу клієнт отримує JWT і передає його в заголовку.
- Студент бачить лише курси своєї групи, викладач керує лише своїми, адміністратор — усім (`access.py`).
- Писати в особисті можна лише людям зі спільних курсів.
- Файли й записи віддаються лише тим, хто має доступ до курсу або простору.

## 8. API

Усі маршрути — під `/api`, потребують JWT, крім `register` і `login`.

| Область | Маршрути |
|---|---|
| Акаунт | `POST register`, `POST login`, `GET/PUT me`, `PUT me/password`, `GET me/dashboard`, `GET me/counters` |
| Курси | `GET/POST courses`, `GET/PUT/DELETE courses/{id}`, `GET courses/{id}/people`, `grades`, `gradebook` |
| Вміст | `POST courses/{id}/topics`, `PUT/DELETE topics/{id}`, `POST topics/{id}/move`, `POST topics/{id}/materials`, `GET/PUT/DELETE materials/{id}`, вкладення |
| Здачі | `POST materials/{id}/submit`, `GET materials/{id}/submissions`, `PUT submissions/{id}/grade`, файли |
| Спілкування | оголошення (`announcements`, `read`, `pin`, `readers`), канали (`channels`, `messages`, `accept`), `dm`, `contacts`, `notifications` |
| Простори | `spaces`, `join` / `leave`, повідомлення, задачі (`space-tasks`), файли (`space-files`) |
| Навчання | `materials/{id}/note`, `flashcards` (+ `review`), `calendar`, `calendar.ics`, `search`, записи лекцій |
| AI | `courses/{id}/ai-settings`, `materials/{id}/summary`, `courses/{id}/ask`, `materials/{id}/flashcards/generate`, `courses/{id}/agent`, `ai/usage` |
| Адмін | `admin/stats`, `admin/users`, `admin/import` |
| Реальний час | WebSocket `/ws?token=…` |

оцінка, оголошення, Q&A, особисті повідомлення, простори, нотатки й картки, AI (зокрема вимкнення AI для лаби),
сповіщення, календар, пошук, адмінка, WebSocket-події, записи лекцій, агент, канали з файлами, дошка задач,

```bash
cd backend && .venv/bin/python -m pytest
```
