# Архітектурні рішення (ADR)

ADR (Architecture Decision Record) — коротка записка про одне важливе рішення: що обрали, з чого обирали, чому і які наслідки. Рятує від повторних суперечок і дає готову відповідь викладачеві на «чому саме так?».

## Як додати

1. Скопіювати [0000-template.md](0000-template.md) у `NNNN-korotka-nazva.md` з наступним номером.
2. Заповнити, відкрити PR, узгодити з командою.
3. Додати рядок у журнал нижче.
