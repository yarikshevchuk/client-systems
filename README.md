# client-systems — VNS

Навчальна платформа замість ВНС Львівської політехніки: курси з темами, матеріалами й файлами, здача лаб з оцінками й відгуками, оголошення з підтвердженням прочитання, Q&A з прийнятими відповідями, особисті повідомлення, навчальні простори, календар дедлайнів, нотатки, флешкартки й AI-помічник. Командний навчальний проєкт для БА й ПКС.

> Папка [`docs/`](docs/README.md) описує ранню ідею («запис лекції → конспект») і застаріла: поточний проєкт — переробка ВНС, див. артефакти БА.

## Склад

| Частина | Що | Стек |
|---|---|---|
| [`backend/`](backend) | API, чат у реальному часі (WebSocket), AI | Python, FastAPI, PostgreSQL (`psycopg`) |
| [`frontend/`](frontend) | екрани | React, Vite, React Router, звичайний CSS (власні компоненти) |
| [`docker-compose.yml`](docker-compose.yml) | база даних | PostgreSQL 16, порт 5440 |

## Запуск

Потрібні Docker, Python 3.10+ і Node 20+.

```bash
docker compose up -d db
```

```bash
cd backend
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000
```

```bash
cd frontend
npm install
npm run dev
```

Відкрити http://localhost:5173. При першому запуску схема створюється, а база заповнюється демо-даними ([`seed.py`](backend/seed.py)): адмін, двоє викладачів, сім студентів двох груп, п'ять курсів, здані роботи з оцінками, оголошення, питання з відповідями, повідомлення, простори, картки. На сторінці входу є кнопки демо-акаунтів (пароль демо-акаунтів — `DEMO_PASSWORD` у `seed.py`). Є також реєстрація.

Адреса бази: `DATABASE_URL` (за замовчуванням `postgresql://vns:vns@127.0.0.1:5440/vns`). Почати з чистих даних: `docker compose down -v`, потім знову `up -d db`.

Тести бекенду (потрібна запущена база; тести створюють власну базу `vns_test`): `cd backend && .venv/bin/python -m pytest`.

## Можливості

**Студент:** дашборд з дедлайнами, оголошеннями й прогресом; курс (теми, лекції, лаби, файли); здача лаби з коментарем, оцінка й відгук; прогноз оцінки («зароблено / результат за оціненими / максимум») і калькулятор «що потрібно, щоб набрати N %»; Q&A з гілками відповідей; загальний чат курсу; особисті повідомлення; навчальні простори; календар з експортом `.ics`; нотатки до матеріалів; флешкартки з інтервальним повторенням; AI (конспект, питання, картки); глобальний пошук; сповіщення в реальному часі (оцінки, відповіді, оголошення, нагадування про дедлайни за 72 і 24 години).

**Викладач:** створення курсів, тем і матеріалів (редагування, видалення, порядок, прикріплені файли); оголошення з закріпленням і списком тих, хто прочитав; журнал оцінок із CSV й позначкою «відстає»; перевірка робіт з оцінкою й відгуком; прийняття відповідей у Q&A; налаштування AI для курсу; налаштування курсу.

**Адмін:** статистика платформи, користувачі й ролі.

## AI

Без ключа AI працює в **демо-режимі** (конспект — перші речення, відповідь — речення з найближчого матеріалу, картки — речення з пропущеним словом; на екрані позначка «demo mode»). З ключем відповіді генерує Claude:

```bash
export ANTHROPIC_API_KEY=...        # ключ не комітити
export AI_MODEL=claude-sonnet-5-5   # необов'язково
export AI_DAILY_LIMIT=30            # запитів на користувача за добу
```

Правила: AI вимкнений для курсу, доки викладач його не ввімкне (Course settings); відповідь лише за матеріалами курсу, інакше «Not found in the course materials» і кнопка «Ask the group»; для оцінюваних лаб лише підказки; конспект зберігається й повторно не генерується й не витрачає ліміт.

## Будова коду

- `backend/`: по одному модулю на область (`courses`, `submissions`, `announcements`, `discussion`, `dm`, `spaces`, `study`, `ai`, `notifications`, `schedule`, `search`, `admin`), `db.py` (схема й три функції `select`/`one`/`execute`), `live.py` (WebSocket-хаб подій), `access.py` (права).
- `frontend/src/`: `pages/` (екрани), `components/` (спільні блоки), `components/ui.jsx` (власні елементи: список, календар, завантаження файлу, перемикачі, модальні вікна, меню, повідомлення), `live.jsx` (одне WebSocket-з'єднання, підписки на події), `api.js`.
