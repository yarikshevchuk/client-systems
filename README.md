# client-systems

Вебзастосунок для учнів: записуєш лекцію в браузері або імпортуєш аудіофайл — отримуєш зручний конспект, у якому можна швидко знайти потрібну інформацію.

Командний навчальний проєкт: повноцінний фронтенд + базовий бекенд.
