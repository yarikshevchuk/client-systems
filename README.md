# client-systems — VNS

Навчальна платформа замість ВНС Львівської політехніки: курси з темами й матеріалами, здача лаб з оцінками й чесним прогнозом, питання курсу в чаті (Q&A) і AI-помічник (конспект лекції, питання за матеріалами курсу). Командний навчальний проєкт для БА й ПКС.

> Папка [`docs/`](docs/README.md) описує ранню ідею («запис лекції → конспект») і застаріла: поточний проєкт — переробка ВНС, див. артефакти БА.

## Склад

| Частина | Що | Стек |
|---|---|---|
| [`backend/`](backend) | API, база, чат (WebSocket), AI | Python, FastAPI, SQLite |
| [`frontend/`](frontend) | екрани | React, Vite, React Router, звичайний CSS |

База — один файл `backend/app.db`; при першому запуску створюється й заповнюється демо-даними ([`seed.py`](backend/seed.py)): викладач, двоє студентів, курс «Algorithms and Data Structures» (AI увімкнено) і «Databases» (AI вимкнено, як за замовчуванням).

## Запуск

Потрібні Python 3.10+ і Node 20+.

```bash
cd backend
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000
```

```bash
cd frontend
npm install
npm run dev
```

Відкрити http://localhost:5173. На сторінці входу є кнопки демо-акаунтів (пароль демо-акаунтів — `DEMO_PASSWORD` у [`seed.py`](backend/seed.py)). Щоб почати з чистих даних, зупинити бекенд і видалити `backend/app.db` та `backend/uploads/`.

Тести бекенду: `cd backend && .venv/bin/python -m pytest`.

## AI

Без ключа AI працює в **демо-режимі** (конспект — перші речення лекції, відповідь — речення з найближчого матеріалу; на екрані позначка «demo mode»). З ключем відповіді генерує Claude:

```bash
export ANTHROPIC_API_KEY=...        # ключ не комітити
export AI_MODEL=claude-sonnet-5-5   # необов'язково
```

Правила: AI вимкнений для курсу, доки викладач його не ввімкне (Course settings); відповідь лише за матеріалами курсу, інакше «Not found in the course materials» і кнопка «Ask the group»; для оцінюваних лаб лише підказки; конспект зберігається й повторно не генерується.

## Що де

- Вхід: JWT, токен у `localStorage`; ролі `student` і `teacher`.
- Дашборд студента: дедлайни лаб, які ще не здано, і три числа за курсом (зароблено / результат за оціненими роботами / максимум можливих).
- Курс: теми, матеріали (лекції й лаби), вкладка Q&A (чат у реальному часі), вкладка Grades.
- Лаба: умова, дедлайн, здача файлу (до 20 MB), питання викладачу; викладач бачить здачі, завантажує файли й ставить оцінки.
- Налаштування курсу (викладач): AI-перемикачі, додати тему, додати матеріал; сторінка підвантажується окремо (lazy loading).
